# Global Digital Bank – Activities 1 to 5 (Java)

| Folder | Activities | Run |
|---|---|---|
| activity1-2 | 1 Account, 2 TestAccount | `javac -d out *.java && java -cp out TestAccount` |
| activity3-4 | 3 AccountEnhanced, 4 TestAccountEnhanced | `javac -d out *.java && java -cp out TestAccountEnhanced` |
| activity5   | 5 Account with custom exceptions | `javac -d out *.java && java -cp out DemoAccountExceptions` |

Each folder is self-contained (no packages, no dependencies). Requires JDK 11+.
